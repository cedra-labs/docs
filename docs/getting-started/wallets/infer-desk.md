## Download

[**Download Infer Desk**](https://inferenco.com/infer-desk)

## Installation

1. Download Infer Desk for your operating system from the link above
2. Run the installer:
   - **Windows**: Run the `.exe` installer
   - **macOS**: Extract the Zip file and move to Applications
   - **Linux**: Use the AppImage
   - **FreeBSD**: Use the FreeBSD-specific build
3. Launch Infer Desk from your applications menu
4. On the Vault Selection screen, choose a folder location for your new vault
5. Enter and confirm a strong Wallet password to encrypt your vault data
6. Create a new account or import an existing one
7. Your vault and first account are ready to use!

## Supported Platforms
- Windows (x64)
- macOS (Intel & Apple Silicon)
- Linux (x64 & ARM64)
- FreeBSD
