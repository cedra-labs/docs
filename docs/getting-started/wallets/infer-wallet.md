**Infer Wallet** is the official mobile wallet for the Cedra blockchain. Available on Android, Infer Wallet provides a secure and user-friendly way to manage your digital assets.

![Infer Wallet Screenshot](/img/infer-ecosystem/infer-wallet/light.png)

## Download

[**Get Infer Wallet**](https://inferenco.com/infer-wallet)

Or on Google Play: [**com.inferenco.novawallet**](https://play.google.com/store/apps/details?id=com.inferenco.novawallet)

## Installation

1. Download Infer Wallet from the Inferenco website
2. Install the application on your Android device
3. Open the app and follow the setup instructions
4. Create a new wallet or import an existing one
5. Your wallet is ready to use!
